# First Principles website

The site behind https://firstprinciples.courses, served by GitHub Pages.

- `index.html`: the whole page (the hero replays the video ident: a market chart, a dive into one point, the point becomes the dot on the i).
- Fonts: CMU Serif (Computer Modern) from the npm package computer-modern 0.1.3 (SIL Open Font License). The deploy workflow (`.github/workflows/pages.yml`) adds them at publish time.
- `CNAME`: the custom domain.
